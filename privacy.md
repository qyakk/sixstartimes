# Privacy Policy

_Last updated: November 19, 2026_

Six Star Times Uploader ("the app") is a private tool run by Six Star Times. Only the channel owner uses it, to publish Six Star Times videos to the channel's own accounts.

## What the app accesses

With the owner's permission, the app uses YouTube API Services, the Instagram API and the TikTok Content Posting API to upload videos, titles, descriptions and thumbnails to the Six Star Times accounts. It does not collect, read or store information about viewers, commenters or any other users.

## How data is stored

The only data the app keeps is the sign-in tokens for the owner's own accounts. They are stored as encrypted secrets in a private GitHub repository and are used only to upload videos. Nothing is sold, shared with third parties or used for advertising.

## YouTube API Services

This app uses YouTube API Services. By using it you agree to be bound by the [YouTube Terms of Service](https://www.youtube.com/t/terms). Google's handling of data is described in the [Google Privacy Policy](https://policies.google.com/privacy).

## Removing access

You can revoke the app's access to a Google account at any time on the Google security settings page: [myaccount.google.com/permissions](https://myaccount.google.com/permissions). Instagram access can be removed under Settings > Apps and websites, and TikTok access under Settings > Security > Manage app permissions.

## Deleting data

Revoking access as above stops the app immediately. To have stored tokens deleted, email qyakkcontact@gmail.com; they are deleted within 7 days.
